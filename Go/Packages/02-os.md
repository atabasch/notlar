# import "os"

Dosya, dizin ve işletim sistemi ile ilgili işlemler için kullanılır.


| Fonksiyon   | Açıklama                                 | Kısaca Kullanım Örneği          |
| ----------- | ---------------------------------------- | ------------------------------- |
| `Open()`    | Dosya açar, okuma amaçlı                 | `f, err := os.Open("a.txt")`    |
| `Create()`  | Dosya oluşturur (varsa üzerine yazar)    | `f, err := os.Create("a.txt")`  |
| `Remove()`  | Dosya veya dizin siler                   | `err := os.Remove("a.txt")`     |
| `Mkdir()`   | Dizin oluşturur                          | `os.Mkdir("klasor", 0755)`      |
| `Getwd()`   | Geçerli çalışma dizinini döner           | `dir, _ := os.Getwd()`          |
| `Chdir()`   | Çalışma dizinini değiştirir              | `os.Chdir("/tmp")`              |
| `Exit()`    | Programı belirli bir kod ile sonlandırır | `os.Exit(1)`                    |
| `Stat()`    | Dosya/dizin hakkında bilgi alır          | `info, err := os.Stat("a.txt")` |
| `Environ()` | Ortam değişkenlerini dizi olarak döner   | `env := os.Environ()`           |
