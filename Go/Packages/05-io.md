# import "ip"

Akış (stream) tabanlı veri okuma/yazma için temel arayüz ve fonksiyonlar.

| Fonksiyon / Tip       | Açıklama                                           | Kullanım Örneği                             |
| --------------------- | -------------------------------------------------- | ------------------------------------------- |
| `io.Reader`           | Okuma arayüzü (`Read([]byte) (int, error)`)        | Her veri kaynağı (dosya, ağ) için temel tip |
| `io.Writer`           | Yazma arayüzü (`Write([]byte) (int, error)`)       | Her veri hedefi için temel tip              |
| `io.ReadFull()`       | Verilen tampon dolana kadar okur                   | `io.ReadFull(r, buf)`                       |
| `io.ReadAtLeast()`    | En az X byte okuyana kadar okur                    | `io.ReadAtLeast(r, buf, min)`               |
| `io.Copy()`           | Tüm veriyi bir kaynaktan bir hedefe kopyalar       | `io.Copy(dst, src)`                         |
| `io.CopyN()`          | Belirtilen kadar byte kopyalar                     | `io.CopyN(dst, src, n)`                     |
| `io.LimitReader()`    | Reader’ı X byte ile sınırlar                       | `io.LimitReader(r, n)`                      |
| `io.MultiReader()`    | Çoklu reader’ı ard arda birleştirir                | `io.MultiReader(r1, r2)`                    |
| `io.MultiWriter()`    | Yazmayı birden fazla hedefe yönlendirir            | `io.MultiWriter(w1, w2)`                    |
| `io.TeeReader()`      | Okunan veriyi hem okur hem başka bir yere kopyalar | `io.TeeReader(r, w)`                        |
| `io.Pipe()`           | Bellekte bir Reader ve Writer oluşturur            | `r, w := io.Pipe()`                         |
| `io.SectionReader`    | Büyük dosyada belirli bir bölümü okur              | Kullanımı File ile birlikte                 |
| `io.NopCloser()`      | Reader’a gereksiz bir Close() ekler                | `io.NopCloser(r)`                           |
| `io.Discard`          | Her yazılanı yutan boş bir Writer                  | `io.Copy(io.Discard, r)`                    |
| `io.EOF`              | Okumanın bittiğini belirten hata                   | `err == io.EOF`                             |
| `io.ErrClosedPipe`    | Kapalı pipe’a erişimde hata                        | Genelde pipe ile                            |
| `io.ErrShortBuffer`   | Buffer çok küçük                                   | ReadAt fonksiyonları                        |
| `io.ErrUnexpectedEOF` | Okuma tamamlanmadan EOF geldi                      |                                             |
| `io.NewSectionReader` | Belirli bölümü okuyan SectionReader oluşturur      |                                             |
| `io.NewReaderAt`      | Rastgele erişim ile okuma (interface)              |                                             |
