Temel ve ileri düzey matematik fonksiyonları.

| Fonksiyon             | Açıklama                                | Kullanım Örneği                    |
| --------------------- | --------------------------------------- | ---------------------------------- |
| `Abs()`               | Mutlak değer                            | `math.Abs(-5.7)`                   |
| `Acos()`              | Arkkosinüs (radyan)                     | `math.Acos(0.5)`                   |
| `Asin()`              | Arksinüs (radyan)                       | `math.Asin(0.5)`                   |
| `Atan()`, `Atan2()`   | Arktanjant (ve iki parametreli)         | `math.Atan(1)`, `math.Atan2(y, x)` |
| `Ceil()`              | Yukarı yuvarlama (en yakın tamsayıya)   | `math.Ceil(4.3)`                   |
| `Copysign()`          | Değerin işaretini değiştirir            | `math.Copysign(3, -1)`             |
| `Cos()`               | Kosinüs                                 | `math.Cos(x)`                      |
| `Degrees()`           | Radyanı dereceye çevirir                | `math.Degrees(3.14)`               |
| `Exp()`               | e^x (üs alma, doğal logaritmanın tersi) | `math.Exp(1)`                      |
| `Expm1()`             | e^x - 1                                 |                                    |
| `Floor()`             | Aşağı yuvarlama (en yakın tamsayıya)    | `math.Floor(4.9)`                  |
| `Hypot()`             | Pisagor bağıntısı (`sqrt(x*x + y*y)`)   | `math.Hypot(3, 4)`                 |
| `Log()`               | Doğal logaritma (e tabanında)           | `math.Log(2.718)`                  |
| `Log10()`             | 10 tabanında logaritma                  | `math.Log10(100)`                  |
| `Log2()`              | 2 tabanında logaritma                   | `math.Log2(8)`                     |
| `Max()`               | En büyük iki sayı                       | `math.Max(2, 7)`                   |
| `Min()`               | En küçük iki sayı                       | `math.Min(2, 7)`                   |
| `Mod()`               | Mod alma (kalanı verir)                 | `math.Mod(10, 3)`                  |
| `Pow()`               | Üs alma                                 | `math.Pow(2, 3)`                   |
| `Pow10()`             | 10’un üssü                              | `math.Pow10(3)`                    |
| `Remainder()`         | Kalanı verir                            |                                    |
| `Round()`             | En yakın tamsayıya yuvarlar             | `math.Round(2.7)`                  |
| `RoundToEven()`       | En yakın çift sayıya yuvarlar           |                                    |
| `Sin()`               | Sinüs                                   | `math.Sin(x)`                      |
| `Sqrt()`              | Karekök                                 | `math.Sqrt(16)`                    |
| `Tan()`               | Tanjant                                 | `math.Tan(x)`                      |
| `Trunc()`             | Ondalığı atar, tam kısmı döner          | `math.Trunc(3.9)`                  |
| `IsNaN()`, `IsInf()`  | Not-a-Number ve Sonsuzluk kontrolü      |                                    |
| `Modf()`              | Tam ve ondalık kısmı ayırır             |                                    |
| `Signbit()`           | Negatif mi kontrolü                     |                                    |
| `Cbrt()`              | Küpkök                                  | `math.Cbrt(27)`                    |
| `Gamma()`             | Gama fonksiyonu                         |                                    |
| `Nextafter()`         | Bir sonraki kayan nokta değerini bulur  |                                    |
| `Pi`, `E`, `Phi`, ... | Sabitler (π, e, altın oran vs.)         | `math.Pi`                          |
