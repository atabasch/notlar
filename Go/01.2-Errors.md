# Hata Yönetimi

- Go'da hata yönetimi basittir. 
- Fonksiyonlar genelde 2 değer döner. 
- 1. Değer fonksiyon işlemininsonucu
- 2. Değer hata varsa hata döner eğer hata yoksa `nil` döner.


## Temel

**Go'da hatalar `error` adında `interface` lerdir ve `Error` anahtarı ile bir string değer alırlar.**

```go
type error interface {
    Error() string
}
```

### Fonksiyondna hata alma örneği

```go
var result, err = funcName(params) // result: fonksiyonun sonucu, err: hata mesajı yoksa nil

if err != nil {
    // Eğer "err" "nil" değeri olarak gelmemiş ise o zaman hata var demektir.
}

```



## Hatanı oluştur
```go
import "errors"

myerr := errors.New("Hata açıklaması")
myerr.Error() // yazıyı verir.
```
