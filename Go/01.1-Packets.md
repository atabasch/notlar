Genel Paketeler: Go  klasöründeki /src klasörü altındadır.

Özel paket içindeki fonksiyonlar büyük harfle başlasın


- project_folder/matematik/toplama.go
- project_folder/matematik/cikarma.go
- project_folder/matematik/silme.go
- project_folder/matematik/bolme.go

Tüm kodlar tek dosyada yazılabilir.
```go
//toplama.go
package matematik

func Topla(a, b int){ // Func ismi küçük harfle başlarsa private olur.
     return a+b
}
```


## Uygulamayı modüler yap

```bash
go mod init customappname 
```

## Modülleri kullan

```go
package main

import "customappname/matematik"

func main(){
    matematik.Topla(10, 20)
    matematik.Bol(100, 10)
}
```


# GO Paketleri

| Paket Adı       | Ne İşe Yarar?                                 | Ne Zaman Kullanılır?                                            | Örnek Kullanım                  |
| --------------- | --------------------------------------------- | --------------------------------------------------------------- | ------------------------------- |
| `fmt`           | Formatlı çıktı, yazdırma ve okuma             | Konsola veri yazarken, kullanıcıdan girdi alırken               | `fmt.Println()`, `fmt.Scan()`   |
| `os`            | Dosya, dizin işlemleri, ortam değişkenleri    | Dosya/dizin oluşturma, okuma, silme, programdan çıkış           | `os.Open()`, `os.Exit()`        |
| `io`            | Akış (stream) tabanlı okuma/yazma             | Dosya/stream ile veri aktarırken, custom Reader/Writer yazarken | `io.Copy()`, `io.Reader`        |
| `bufio`         | Buffer'lı okuma/yazma                         | Çok satırlı/çoklu veri okurken, Scanner ile satır satır okuma   | `bufio.Scanner`                 |
| `strconv`       | String <-> int, float, bool dönüşümleri       | String’i sayıya ya da tam tersi çevirirken                      | `strconv.Atoi()`, `Itoa()`      |
| `strings`       | String üzerinde işlem yapma                   | Parçalama, birleştirme, arama, değiştirme                       | `strings.Split()`, `ToUpper()`  |
| `time`          | Tarih, saat işlemleri, timer, formatlama      | Şu anki zamanı almak, timer kurmak, zaman aritmetiği            | `time.Now()`, `Sleep()`         |
| `math`          | Matematiksel fonksiyonlar (karekök, log, vs.) | İleri matematik işlemlerinde                                    | `math.Sqrt()`, `math.Pow()`     |
| `errors`        | Hata oluşturma ve hata yönetimi               | Kendi hata mesajlarını tanımlamak                               | `errors.New()`                  |
| `log`           | Basit loglama                                 | Hata, bilgi, uyarı loglarını konsola/ dosyaya yazmak            | `log.Println()`, `log.Fatal()`  |
| `net/http`      | HTTP sunucu/istemci yazmak                    | API, web server, HTTP istekleri atmak/almak                     | `http.ListenAndServe()`         |
| `encoding/json` | JSON kodlama/çözme                            | JSON verisi ile çalışmak (REST API, veri transferi, vs.)        | `json.Marshal()`, `Unmarshal()` |
| `path/filepath` | Dosya/dizin yolları ile işlem yapmak          | Dosya yollarını birleştirirken, ayrıştırırken                   | `filepath.Join()`, `Split()`    |
| `regexp`        | Regular Expression (düzenli ifade) işlemleri  | Karmaşık string aramaları, pattern ile eşleştirme               | `regexp.MustCompile()`          |
| `sync`          | Paralel programlama, kilitler, WaitGroup      | Goroutine’leri senkronize etmek, veri yarışını engellemek       | `sync.Mutex`, `sync.WaitGroup`  |
| `context`       | İşlemler arası bağlam, iptal ve zaman aşımı   | API isteklerinde, uzun süren işlemleri iptal etmek için         | `context.Background()`          |
| `reflect`       | Tip yansıtma, dinamik tip işlemleri           | Bilinmeyen tiplerle çalışma, generic kod yazmak                 | `reflect.TypeOf()`              |
